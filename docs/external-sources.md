# External sources

External resources may be discovered through Google or another search engine, but search results do not grant redistribution rights.

The project includes a source manifest for open-license candidates from SVG Repo. Each icon must be checked at its original source page before import. CC0 is preferred for frictionless redistribution.

## Google Material Icons

Official Google Material Icons are Apache-2.0. Use `bun run icons:import:google` to vendor the exact SVG from the official repository. The importer is intentionally separate from the normal publish pipeline so a temporary network outage cannot break an otherwise local build.
