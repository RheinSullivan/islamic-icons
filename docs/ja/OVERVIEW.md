# 概要 (Overview)

Atsarul Mujahidin（アサール・ル・ムジャヒディン）は、現代のWebアプリケーション向けに設計されたフレームワーク非依存のイスラムSVGおよびWebPアイコンライブラリです。

## 特徴と設計思想

1. **高品質なアイコンコレクション**: モスク、礼拝、コーラン、ラマダン、パレスチナ連帯など、本物のイスラム美術と文化を尊重したアイコンを収録。
2. **明確な出典管理（Source-Aware）**: 各アイコンの原作者、出典URL、ライセンス情報を完全にメタデータとして記録。
3. **主要フレームワーク対応**: React, Vue, Svelte, Angular, Astro 向けのネイティブコンポーネントおよびバニラHTML用Webコンポーネントを提供。
4. **人道支援への貢献**: 寄付金の最低70%をパレスチナ支援をはじめとする人道支援プログラムに充当。
