# はじめに

## Atsarul Mujahidinとは？

Atsarul Mujahidinは、最新のデジタルプロジェクトでイスラムのアイコンを表示するための高品質なベクター（SVG）とラスター（WebP）のコレクションを提供するオープンソースのアイコンライブラリです。このライブラリは、**ソース認識**、**フレームワーク非依存**、**帰属優先**の原則に基づいて構築されています。

### 主な特徴

- **81以上の厳選されたアイコン** - モスクの建築、礼拝、コーランの写本、ラマダン、人道連帯のシンボルのコレクション
- **完全なフレームワークサポート** - React、Next.js、Vue、Nuxt、Svelte、SvelteKit、Angular、Astro、プレーンHTMLでネイティブに動作
- **ソース帰属と出所** - すべてのアートワークには、作成者、ソースURL、元のライセンス、再配布許可履歴が含まれます
- **多様なバリエーション** - 各論理アイコンのfill（塗りつぶし）、outline（アウトライン）、color（カラー）バリアント
- **ツリーシェイク可能＆ゼロランタイム** - 使用するアイコンのみをパッケージし、ランタイムでのリモートAPI呼び出しなし
- **多言語対応** - インドネシア語、英語、アラビア語、日本語での完全なドキュメント

## なぜAtsarul Mujahidin？

一般的なアイコンライブラリとは異なり、Atsarul Mujahidinはイスラムのデジタル表現のニーズに特化して作成されました：

1. **本物で検証されたソース** - 信頼できるコミュニティの作品とイスラム美術アーカイブから編纂
2. **文化的配慮** - イスラムの美術規範とマナーを尊重
3. **ライセンスの透明性** - 検索エンジンからライセンスを推測することなく、オープンな法的情報
4. **人道支援** - パレスチナと人道的社会プログラムへの真の連帯

## 哲学と原則

このライブラリは3つの核心原則に基づいて設計されています：

### 1. 認識可能なアイコン

イスラム教徒と開発者が即座に理解できるアイコン - モスク、カーバ神殿、タスビー、コーラン、ランタンなど。各アイコンは明確な文化的・宗教的意味を持っています。

### 2. 追跡可能なソース

すべてのアセットは完全な出所を持っています - 作成者の帰属、ソースURL、ライセンス条項、メタデータに記録された再配布許可。推測なし、曖昧さなし - すべてが文書化されています。

### 3. フレームワーク非依存

Reactや単一のフレームワークに縛られません。アセットはプレーンなSVG/WebPファイルで、すべての最新フレームワークのための便利なアダプタレイヤーを備えています。

## 何が違うのか？

ほとんどのアイコンライブラリはGoogle Image Searchをライセンスとして扱います。Atsarul Mujahidinは発見とライセンスを別々のものとして扱います。Googleは単なる発見ツールです - 元のソースと再配布条件が検証され記録された後にのみ、アイコンが配布可能なライブラリに入ります。

> **核心ルール:** Googleは発見ツールであり、ライセンスではありません。アイコンは、元のソースと再配布条件がアセットメタデータに記録された後にのみ、配布可能なライブラリに入ります。

## 技術アーキテクチャ

ライブラリは、以下の構造を持つ標準的なnpmパッケージとして配信されます：

- **ソースアセット:** セマンティックカテゴリ（礼拝、ラマダン、シンボルなど）によって整理された元のSVG/WebPファイル
- **フレームワークアダプター:** React、Vue、Svelte、Angular、Astro用の事前構築されたコンポーネント
- **Vanilla JS:** CDNサポート付きのWebコンポーネント（Bootstrap Iconsのように）
- **メタデータ:** ソースURL、ライセンス、作成者、帰属要件を含むJSONファイル
- **ビルドパイプライン:** Bunベースのカタログ生成、検証、パッケージング

## 人道支援

Atsarul Mujahidinは100％の財務透明性を持って公的寄付を受け入れます。すべての資金の最低70％が人道支援（パレスチナ救済、孤児院、低所得家庭、高齢者ケア、災害救済）に直接充てられます。最大30％はライブラリの可用性を維持するために必要なインフラストラクチャ（サーバー、CDN、ドメイン料金）をサポートします。
