## Atsarul Mujahidinとは？

**Atsarul Mujahidin**（آثَارُ المُجَاهِدِيْنَ）はアラビア語で「ムジャヒディンの足跡」を意味します - それは戦う人々のために作り、残すものを表しています。この名前は、闘う人々に永続的な影響を与える意味のある作品を構築する哲学を反映しています。

### 主な特徴

- **81以上の厳選されたアイコン** - モスク、礼拝、コーラン、ラマダン、人道連帯シンボルのコレクション
- **完全なフレームワークサポート** - React、Next.js、Vue、Nuxt、Svelte、SvelteKit、Angular、Astro、プレーンHTMLでネイティブに動作
- **完全なソース追跡** - すべてのアートワークに作成者、ソースURL、元のライセンス、再配布許可履歴が含まれています
- **多様なバリエーション** - 各論理アイコンのfill（塗りつぶし）、outline（アウトライン）、color（カラー）バリアント
- **ツリーシェイク可能＆ゼロランタイム** - 使用するアイコンのみをパッケージし、ランタイムでのリモートAPI呼び出しなし
- **多言語対応** - アラビア語、インドネシア語、英語、日本語での完全なドキュメント

## 哲学と目標

このライブラリは特別な使命を持って作成されました：高品質のイスラムアイコンを提供しながら、人道支援をサポートする。このコレクションの各アイコンには二重の目的があります - 最新のWeb開発での実用的な有用性と、イスラムの価値観と実践の象徴的な表現。

### 核心原則

1. **認識可能なアイコン** - イスラム教徒と開発者が即座に理解できるアイコン - モスク、カーバ神殿、タスビー、コーラン、ランタンなど
2. **追跡可能なソース** - すべてのアセットは完全な出所を持っています - 作成者の帰属、ソースURL、ライセンス条項、メタデータに記録された再配布許可
3. **フレームワーク非依存** - Reactや単一のフレームワークに縛られません。アセットはプレーンなSVG/WebPファイルで、React、Vue、Svelte、Angular、Astro、プレーンHTMLのための便利なアダプタレイヤーを備えています

## 人道支援

Atsarul Mujahidinは100％の財務透明性を持って公的寄付を受け入れます。すべての資金の最低70％が人道支援（パレスチナ救済、孤児院、低所得家庭、高齢者ケア、災害救済）に直接充てられます。最大30％はライブラリの可用性を維持するために必要なインフラストラクチャ（サーバー、CDN、ドメイン料金）をサポートします。

## オープンソースとコミュニティ

これはコミュニティベースのプロジェクトです。貢献者はアートワークを提供し、ドキュメントを改善し、フレームワークアダプターを追加し、ソースライセンスのレビューを支援します。このライブラリは、開発者、デザイナー、イスラム技術コミュニティにとって意味のあるものを構築したい人からの貢献を歓迎します。
