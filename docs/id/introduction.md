# Pengenalan

## Apa itu Atsarul Mujahidin?

Atsarul Mujahidin adalah library ikon sumber terbuka (open-source) yang menyediakan koleksi vektor (SVG) dan raster (WebP) berkualitas tinggi untuk menampilkan ikonografi Islam dalam proyek-proyek digital modern. Library ini dibangun dengan prinsip **sadar sumber (source-aware)**, **framework-agnostic**, dan **mengutamakan atribusi (attribution-first)**.

### Fitur Utama

- **81+ Ikon Terkurasi** - Koleksi arsitektur masjid, sholat, mushaf Al-Qur'an, Ramadan, dan simbol solidaritas kemanusiaan.
- **Dukungan Framework Penuh** - Bekerja secara bawaan pada React, Next.js, Vue, Nuxt, Svelte, SvelteKit, Angular, Astro, dan HTML biasa.
- **Atribusi & Asal-usul Sumber** - Setiap karya seni menyertakan pencipta, URL sumber, lisensi asli, dan riwayat izin redistribusi.
- **Beragam Varian** - Varian fill (padat), outline (garis), dan color (warna-warni) untuk setiap ikon logis.
- **Tree-Shakeable & Nol Runtime** - Hanya mengepak ikon yang Anda gunakan tanpa pemanggilan API jarak jauh saat runtime.
- **Multi-bahasa** - Dokumentasi lengkap dalam Bahasa Indonesia, Inggris, Arab, dan Jepang.

## Mengapa Atsarul Mujahidin?

Tidak seperti library ikon umum, Atsarul Mujahidin dibuat khusus untuk kebutuhan representasi digital Islam:

1. **Sumber Asli & Terverifikasi** - Disusun dari karya komunitas tepercaya dan arsip seni Islam.
2. **Sensitivitas Budaya** - Menghormati kaidah seni dan adab Islam.
3. **Transparansi Lisensi** - Informasi legalitas terbuka tanpa menebak lisensi dari mesin pencari.
4. **Dukungan Kemanusiaan** - Solidaritas nyata untuk Palestina dan program sosial kemanusiaan.
