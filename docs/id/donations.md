# Donasi & Transparansi Kemanusiaan

Atsarul Mujahidin menerima donasi publik dengan 100% transparansi keuangan. Kebijakan ini terbuka dan jelas agar setiap kontributor memahami bagaimana dana dialokasikan.

## Kebijakan Alokasi

- **Minimum 70%** dari seluruh dana dialokasikan untuk bantuan kemanusiaan.
- Bantuan kemanusiaan mencakup **bantuan Palestina, panti asuhan, keluarga prasejahtera, perawatan lansia, dan tanggap bencana**.
- **Maksimum 30%** digunakan untuk biaya operasional teknis agar Atsarul Mujahidin tetap aktif, termasuk biaya **server, CDN, dan domain**.

Angka 70% adalah batas minimal alokasi kemanusiaan. Jika biaya operasional lebih rendah, sisa dana dialokasikan sepenuhnya untuk misi kemanusiaan.
