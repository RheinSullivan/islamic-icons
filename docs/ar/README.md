## ما هي آثار المجاهدين؟

**آثار المجاهدين** (Atsarul Mujahidin) تعني "آثار المجاهدين" باللغة العربية - وهي تمثل شيئًا تنشئه وتتركه للمقاتلين. يعكس هذا الاسم فلسفة بناء عمل ذي معنى له تأثير دائم لأولئك الذين يكافحون.

### الميزات الرئيسية

- **81+ أيقونة منتقاة** - مجموعة من المساجد، الصلاة، المصحف الشريف، رمضان، ورموز التضامن الإنساني
- **دعم كامل لجميع الأطر** - يعمل محليًا مع React و Next.js و Vue و Nuxt و Svelte و SvelteKit و Angular و Astro و HTML العادي
- **التتبع الكامل للمصادر** - كل عمل فني يتضمن المنشئ وعنوان URL المصدر والترخيص الأصلي وسجل أذونات إعادة التوزيع
- **أشكال متعددة** - أشكال fill (مملوء) و outline (مخطط) و color (ملون) لكل أيقونة منطقية
- **قابل للهز (Tree-shakeable) وبدون وقت التشغيل** - يُحزم فقط الأيقونات التي تستخدمها دون استدعاءات API بعيدة أثناء وقت التشغيل
- **متعدد اللغات** - توثيق كامل باللغة العربية والإندونيسية والإنجليزية واليابانية

## الفلسفة والأهداف

تم إنشاء هذه المكتبة بمهمة خاصة: توفير أيقونات إسلامية عالية الجودة مع دعم العمل الإنساني. كل أيقونة في هذه المجموعة لها غرض مزدوج - الفائدة العملية في تطوير الويب الحديث والتمثيل الرمزي للقيم والممارسات الإسلامية.

### المبادئ الأساسية

1. **الأيقونات المعروفة** - أيقونات يفهمها المسلمون والمطورون على الفور - المساجد والكعبة والمسبحة والقرآن والفانوس وغيرها
2. **مصادر قابلة للتتبع** - كل أصل يحمل مصدرًا كاملاً - إسناد المنشئ وعنوان URL المصدر وشروط الترخيص وأذونات إعادة التوزيع المسجلة في البيانات الوصفية
3. **مستقل عن الإطار** - غير مرتبط بـ React أو أي إطار عمل واحد. الأصول هي ملفات SVG/WebP عادية مع طبقات محول مريحة لـ React و Vue و Svelte و Angular و Astro و HTML العادي

## الدعم الإنساني

تقبل آثار المجاهدين التبرعات العامة بشفافية مالية 100٪. يتم تحويل ما لا يقل عن 70٪ من جميع الأموال مباشرة إلى المساعدات الإنسانية (الإغاثة الفلسطينية، دور الأيتام، الأسر ذات الدخل المنخفض، رعاية المسنين، الإغاثة في حالات الكوارث). يدعم ما يصل إلى 30٪ البنية التحتية (الخوادم، CDN، رسوم النطاق) اللازمة للحفاظ على توفر المكتبة.

## المصدر المفتوح والمجتمع

هذا مشروع قائم على المجتمع. يقدم المساهمون الأعمال الفنية، ويحسنون الوثائق، ويضيفون محولات الإطار، ويساعدون في مراجعة تراخيص المصدر. ترحب المكتبة بالمساهمات من المطورين والمصممين وأي شخص يريد بناء شيء ذي معنى لمجتمع التكنولوجيا الإسلامي.
