# نظرة عامة (Overview)

مجموعة أيقونات إسلامية حديثة ومفتوحة المصدر بصيغ SVG و WebP للتطبيقات الرقمية المعاصرة.

## مقدمة عن آثار المجاهدين

**آثار المجاهدين** (Atsarul Mujahidin) هي مكتبة أيقونات إسلامية مستقلة عن إطارات العمل (Framework-Agnostic)، تم إنشاؤها لتقديم رموز وأعمال فنية إسلامية عالية الدقة مع تتبع كامل للمصادر والتراخيص الأصلية.

### المبادئ الأساسية:
1. **أصالة الرموز**: أيقونات تعبر بدقة عن الثقافة والشعائر الإسلامية مثل المساجد، الصلاة، المصحف الشريف، الكعبة المشرفة، ورموز التضامن الإنساني.
2. **الشفافية الكاملة للمصادر**: كل أيقونة مسجلة مع اسم المؤلف الأصلي، رابط المصدر، ونوع الترخيص القانوني.
3. **التوافق الشامل**: تعمل بسلاسة مع React و Vue و Svelte و Angular و Astro وعناصر الويب القياسية HTML/JS بدون أي تبعات تشغيل ثقيلة.
4. **دعم القضايا الإنسانية**: المكتبة مخصصة لدعم الشعب الفلسطيني الشقيق والمبادرات الخيرية بنسبة تبرعات واضحة بنسبة 100%.
